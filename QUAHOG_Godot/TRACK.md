# QUAHOG_Godot — active Godot track

Parallel Godot 4 (GDScript) track for the same South Coast crime game. Open
`project.godot` with Godot 4.2 or later. Setup and the playable scene are in
[`GODOT_SETUP.md`](GODOT_SETUP.md). See [`../ENGINES.md`](../ENGINES.md).

`QUAHOG_GODOT1/` is a separate Godot 4.6 project (config name "The Narrows")
and is its own parallel track.

This sandbox did not launch Godot, so a Godot playthrough or export is not
claimed.

## History worth keeping

This port started before the browser track. District constants and the
weather/neon flavor here are still part of the game's design language, and
the Mount Hope mission list was cross-checked against the later story pass in
`QUAHOG_GODOT1/scripts/systems/story_mission.gd`. New work on this tree stays
in this tree.
